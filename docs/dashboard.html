What is actually being traded, and why that matters

The deployed strategy is H1, cross-sectional momentum — which this project's own analysis rejected on train-period evidence: net Sharpe 0.47, a bootstrap confidence interval spanning zero, and 36% of its parameter grid beating the benchmark against a pre-declared 60% threshold.

It is deployed because it was rejected. Its parameters were committed to Git before any backtest existed, so running it forward is a clean test of a pre-registered hypothesis rather than a fitted strategy. The question is not "does this make money" but "does live experience agree with the rejection?" It must never be described as a selected or recommended strategy.
A protective-put options overlay also runs here no backtest — free options-chain history does not exist back to 2007, so it was deployed as an explicitly-labelled forward test. Afterwards, AQR's published study of a near-identical specification (5% out-of-the-money one-month puts, 1985–2020) was located: −6.4% annualised, Sharpe −0.61. That prior is recorded in the repository, so premium bleed here is the predicted outcome, not a surprise.
A trend-following strategy was also tested and not deployed: it passed every in-sample test (Sharpe 0.74, Newey–West t = 2.82, 100% of its parameter grid) and then failed validation (Sharpe 0.21), losing 12.7% in the COVID crash it was designed to hedge. The failure and its diagnosis are in the research log.

Why you should not simply believe this page

A self-published dashboard is self-reported, and a sceptical reader is right not to take it at face value. What makes this record checkable is not this page but the Git history behind it: trade journals are committed by an automated nightly job, so timestamps are outside the author's control and any retroactive edit would appear as a history rewrite. The raw files are linked below — read those, not this summary.

The page holds no API credentials. Data is published by a scheduled job that keeps the key server-side, and exposes balances, positions and price history only — nothing that could place an order.
